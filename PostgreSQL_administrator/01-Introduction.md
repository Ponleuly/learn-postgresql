# PostgreSQL Administration for Oracle DBAs - Quickly Transition to Handle Postgresql

## Introduction

### COURSE PURPOSE

- Designed for Oracle DBAs transitioning to PostgreSQL.
- Uses existing Oracle DBA knowledge as the foundation.
- Focuses on quickly understanding PostgreSQL rather than learning
  database administration from zero.
- Continuously compares Oracle and PostgreSQL concepts.

### New PostgreSQL concepts such as:
- TOAST
- VACUUM
- PostgreSQL extensions

are explained separately with practical examples and visualizations.

### PRACTICAL DBA FOCUS

The course includes real-world PostgreSQL DBA scenarios:

- Database cloning between servers
- Replication setup
- Automatic failover
- Load balancing/read traffic to standby databases
- PostgreSQL administration tools
- PostgreSQL extensions

### LEARNING METHOD

1. Study the chapter content and theory.
2. Complete the chapter quiz.
3. Complete the assignment/practical exercise.
4. Proceed to the next chapter.

### COURSE STRUCTURE

- Follow the chapters in sequence.
- Later chapters may depend on concepts covered earlier.
- Theory is explained before practical demonstrations.
- Tools and extensions are introduced before chapters that depend
  on them.

### **KEY TAKEAWAY**

The main purpose of this course is to help Oracle DBAs transition
to PostgreSQL quickly by leveraging their existing Oracle knowledge
and continuously correlating Oracle concepts with PostgreSQL
concepts.
